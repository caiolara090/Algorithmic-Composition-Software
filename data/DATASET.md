# Nottingham Dataset

Este projeto usa a versão limpa do Nottingham Dataset.

Fonte oficial utilizada pelo projeto:
https://github.com/jukedeck/nottingham-dataset

O repositório disponibiliza aproximadamente 1.034 melodias MIDI em `MIDI/melody/`. O projeto baixa esses arquivos automaticamente com:

```bash
python download_dataset.py
```

O dataset não é redistribuído neste pacote; apenas o script de obtenção é incluído.
